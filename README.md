# Idle toys

Small idle toys, one folder per idea. Some may become apps of their own, some may end up inside other apps.

You can play them in the browser at https://utopick.github.io/IdleToys/, where each toy has its best version so far and a button for every round, so you can see how it grew.

## Shared principles
- **Steer, don't control.** Each toy runs on its own. The player can nudge events at any time, but never drives them directly.
- **No HUD, art first.** Text only when there is no other way to convey the information.
- **Idle means calm.** When nobody is touching it, there is no HUD: just the scene and the music.
- **Generative music** fits the scene and the moment (dungeon synth, medieval, synthwave...).
- **The real world where it helps:** real time, light and weather of a chosen place (as in Clockscapes).
- **Detailed pixel art:** PSX-era detail, in the spirit of Psygnosis on the PlayStation; readable and cozy.
- Same habits as the rest of the suite: phones first, free/open fonts and code, code in one `index.html`, graphics as separate files in `art/` so they can be improved on their own.

## Ideas
Each folder's `IDEA.md` is a complete project brief (design, rules, references and the owner's notes): a project can start from it alone. `inspiration/` holds the reference pictures.

- [`dungeon/`](dungeon/IDEA.md): a city on top, a dungeon below; two ecosystems that need each other.
- [`civilization/`](civilization/IDEA.md): an idle civilization that grows from a seed.
- [`drive/`](drive/IDEA.md): a car that drives between real cities; you steer with the lights and the pedal.
